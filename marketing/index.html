FAQ

Common questions

Everything you need to know before getting started.

QDoes Humant require PostgreSQL?

PostgreSQL is the default and recommended database. The launcher can switch to MySQL or SQLite for zero-configuration local development via the database selector in the setup wizard.

QWhat Java version is required?

Java 11 is required by the Spring Boot 2.5 backend. The Maven wrapper handles Maven automatically — no global Maven install needed.

QCan I deploy to a cloud server?

Yes. The deployment generator builds the Angular bundle, packages the Spring Boot JAR, and exports a complete deployment folder with an Nginx reverse proxy config example suitable for Ubuntu VPS, AWS EC2, Render or Railway.

QWhy does npm install need --legacy-peer-deps?

angular-datatables@10 has a peer dependency conflict with Angular 11. The legacy flag is required for npm 7+. The GUI launcher sets this automatically.

QHow does multi-tenancy work?

Each tenant is identified by a unique tenantCode used at login. A TenantResolutionFilter injects tenant context into every request, providing row-level data isolation without separate schemas.

QIs Stripe required for the app to run?

No. Stripe keys default to placeholder values if not configured. All HR modules work independently. Stripe is only needed for the tenant subscription checkout flow.
