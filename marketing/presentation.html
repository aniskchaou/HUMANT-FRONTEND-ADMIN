Technical stack

Frontend — Angular 11

  • Bootstrap 4 for responsive UI
  • RxJS 6 reactive data streams
  • ngx-charts for data visualization
  • Angular DataTables for list views
  • Spring proxy via proxy.conf.json

Backend — Spring Boot 2.5

  • Spring Data JPA with PostgreSQL (default)
  • SQLite & MySQL via launcher dialect switch
  • Spring Security JWT authentication
  • Spring Batch for bulk operations
  • Stripe SDK for payment integration

Delivery & Deployment

GUI Launcher (port 3030)

4-step wizard: prerequisites check, database dialect selector (SQLite/PostgreSQL/MySQL), npm install with progress bar, and start/stop full stack. Database config stored in backend/launcher-config.json.

node launcher.js
# or
launcher.bat

Deployment Generator (port 3040)

Builds Angular bundle, packages Spring Boot JAR, writes application-production.properties, Nginx reverse proxy config, and exports a ready-to-upload folder to deployment-builds/.

node generate-deployment-version.js
# or
generate-deployment-version.bat
